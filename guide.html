Способ 1 — Авто-граббер ссылки Рекомендуется

Method 1 — Auto Link Grabber Recommended

Специальная утилита автоматически перехватывает ссылку на историю круток пока ты открываешь её в игре. Не требует настройки Fiddler. Скачать .exe

A small utility that automatically intercepts your pull history link while you open it in-game. No Fiddler setup required. Download .exe

Программа временно включает локальный прокси, перехватывает запрос к истории круток и автоматически копирует ссылку в буфер обмена. Игровые данные не изменяются.
The utility temporarily enables a local proxy, intercepts the pull history request, and automatically copies the link to your clipboard. No game data is modified.
  • 1 Скачай последний релиз со страницы Releases и запусти R1999LinkGrabber.exe
  • 1 Download the latest release from the Releases page and run R1999LinkGrabber.exe
  • 2 В консоли появится:
  • 2 The console will show:
Proxy enabled: 127.0.0.1:8080 Starting capture... Launch the game and open summon history
  • 3 Запусти Reverse: 1999 и открой страницу истории круток (Summon → Record)
  • 3 Launch Reverse: 1999 and open the pull history page (Summon → Record)
  • 4 Программа автоматически найдёт ссылку и скопирует её:
  • 4 The app will automatically find and copy the link:
=== SUMMON LINK FOUND === https://game-re-en-service.sl916.com/query/summon?... Link copied to clipboard
  • 5 Вставь ссылку в поле 🌐 Импорт по ссылке на главной странице трекера
  • 5 Paste the link into the 🌐 Import by URL field on the tracker's main page
Важно: не закрывай окно консоли крестиком — это может оставить системный прокси включённым. Выходи только через Ctrl + C или позволь программе завершиться самостоятельно после захвата ссылки.
Important: do not close the console window with the X button — this may leave the system proxy enabled. Exit only via Ctrl + C or let the program finish automatically after capturing the link.

Если прокси всё же остался включён: Настройки → Сеть и интернет → Прокси → Настройка прокси вручную → выключи «Использовать прокси-сервер».

If the proxy remains enabled: Settings → Network & Internet → Proxy → Manual proxy setup → disable "Use a proxy server".

Если хочешь запустить Python-скрипт напрямую — нужны Python 3.10–3.12 и зависимости:

To run the Python script directly — requires Python 3.10–3.12 and dependencies:

pip install mitmproxy pyperclip python R1999LinkGrabber.py

Method 2 — Import by URL via Fiddler

Если не хочешь использовать авто-граббер, ссылку можно получить вручную через Fiddler Classic. Скачать Fiddler

If you prefer not to use the auto-grabber, you can get the URL manually via Fiddler Classic. Download Fiddler

  • 1 Запусти Fiddler и игру Reverse: 1999
  • 1 Launch Fiddler and Reverse: 1999
  • 2 Открой историю круток в игре (Summon → Record)
  • 2 Open pull history in-game (Summon → Record)
  • 3 В Fiddler найди запрос вида:
  • 3 In Fiddler find a request like:

https://game-re-en-service.sl916.com/query/summon?userId=xxx&token=xxx

  • 4 Выдели эту строку → ПКМ → Copy → Just URL
  • 4 Select the row → Right-click → Copy → Just URL
  • 5 Вставь ссылку в поле 🌐 Импорт по ссылке на главной странице трекера и нажми кнопку
  • 5 Paste the link into the 🌐 Import by URL field on the tracker's main page and click the button

Способ 3 — Загрузка JSON-файла вручную

Method 3 — Manual JSON File Upload

  • 1 Получи ссылку любым из способов выше
  • 1 Get the URL using any method above
  • 2 Открой ссылку в браузере
  • 2 Open the URL in your browser
  • 3 Сохрани страницу как файл: ПКМ по странице → Сохранить как
  • 3 Save the page as a file: Right-click → Save As
  • 4 На главной странице нажми 📂 Выбрать файл и выбери сохранённый JSON
  • 4 On the main page click 📂 Select File and choose the saved JSON
Внимание: кнопка «📂 Выбрать файл» принимает только оригинальный файл из игры. Для загрузки ранее сохранённой базы трекера используй кнопку «📂 Загрузить базу данных».
Note: the «📂 Select File» button only accepts the original in-game file. To load a previously saved tracker database, use the «📂 Load Database» button instead.

Работа с профилями

Managing Profiles

  • Создать новый профиль — кнопка ➕
  • Create a new profile — click ➕
  • Переключить профиль — выпадающий список
  • Switch profiles — use the dropdown
  • Удалить профиль — кнопка ➖ (стандартный профиль удалить нельзя, только очистить)
  • Delete a profile — click ➖ (the default profile cannot be deleted, only cleared)
Профили хранятся локально в браузере. Для переноса на другое устройство используй 💾 Скачать базу данных или подключи Google Диск — тогда все профили синхронизируются автоматически.
Profiles are stored locally in the browser. To transfer to another device, use 💾 Download Database or connect Google Drive — all profiles will sync automatically.

Экспорт и импорт базы данных

Export & Import Database

  • 💾 Скачать базу данных — сохраняет все профили в один JSON-файл для резервной копии или переноса на другое устройство
  • 💾 Download Database — saves all profiles into a single JSON file for backup or transfer to another device
  • 📂 Загрузить базу данных — загружает ранее сохранённый файл базы
  • 📂 Load Database — loads a previously saved database file
При загрузке файла трекер сравнивает каждый профиль с локальными данными. Если профиль из файла совпадает — он игнорируется. Если в файле круток больше — профиль обновляется автоматически. Если в файле круток меньше — появится окно с выбором: оставить локальный или заменить данными из файла.
When loading a file, the tracker compares each profile with local data. If a profile from the file matches — it is ignored. If the file has more pulls — the profile is updated automatically. If the file has fewer pulls — a dialog appears to choose whether to keep local data or replace it.
Внимание: кнопка «📂 Загрузить базу данных» предназначена только для файлов, ранее сохранённых через «💾 Скачать базу данных». Для загрузки оригинального файла из игры используй кнопку «📂 Выбрать файл».
Note: the «📂 Load Database» button is only for files previously saved via «💾 Download Database». To load the original in-game file, use the «📂 Select File» button.

Синхронизация с Google Диском

Google Drive Sync

Трекер поддерживает автоматическую синхронизацию всех профилей через Google Drive. Данные хранятся в скрытой папке приложения — они не отображаются в твоём Диске.

The tracker supports automatic sync of all profiles via Google Drive. Data is stored in a hidden app folder — it does not appear in your Drive.

  • 1 Нажми Подключить Google Диск в блоке управления базой данных
  • 1 Click Connect Google Drive in the database management section
  • 2 Войди в аккаунт Google и разреши доступ
  • 2 Sign in to your Google account and grant access
  • 3 Трекер автоматически загрузит данные из облака и в дальнейшем будет сохранять изменения сам
  • 3 The tracker will automatically load data from the cloud and save changes going forward
После подключения статус изменится на Подключено. При каждом импорте круток данные автоматически сохраняются в облако через 2 секунды после последнего изменения.
After connecting, the status changes to Connected. After each pull import, data is automatically saved to the cloud 2 seconds after the last change.
Подключение сохраняется между сессиями. При следующем открытии трекер автоматически восстановит соединение и синхронизируется без необходимости входить заново.
The connection persists between sessions. On the next visit, the tracker will automatically reconnect and sync without requiring a new sign-in.
Конфликты: если в облаке данных больше — они применяются автоматически. Если меньше — появится окно с выбором.
Conflicts: if the cloud has more data — it is applied automatically. If less — a dialog appears for you to choose.
